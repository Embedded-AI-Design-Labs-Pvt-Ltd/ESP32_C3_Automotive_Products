3. Deadlock and inversion rules

  1. Lock order is global: HAL bus mutex → table mutex. Never reverse.
  2. A task holds at most one mutex while calling into a lower layer that may block.
  3. CAN TX task never calls BLE stack APIs (priority / stack inversion risk).
  4. Logger never takes driver mutexes; it only drains a ring.
  5. Watchdog never blocks on a mutex; it only reads atomics / event bits.
