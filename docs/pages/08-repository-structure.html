Include rules

FromMay includeMust not include
Applicationservices, protocols (public), middlewareESP-IDF, driver internals
Servicesprotocols, middleware, commondrivers, IDF
Protocolscommon, framework, HAL typesIDF, product headers
Middlewarecommon, HAL, FreeRTOSUDS, product
DriversHAL, IDF, BSPUDS, BLE app logic

File naming

C: can_driver.c/.h, can_service.c/.h, isotp.c/.h, uds_server.c/.h, uds_client.c/.h. Prefix public APIs with ae_ or module name as in document 07.
