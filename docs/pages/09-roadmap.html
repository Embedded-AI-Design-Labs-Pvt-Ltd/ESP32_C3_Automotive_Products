Implementation rule after approval

One phase at a time. Each phase: implement module → unit tests → review agent findings → next phase. Do not open all 17 products in one change set.

Ports and cloud

  • Virtual ECU HAL stubs begin in Phase 3 so GUI/HIL can proceed without boards.
  • Arduino and Raspberry Pi 5 ports start after Phase 11 (UDS) unless you prioritize a port earlier.
  • Docker/Jenkins in Phase 19; Terraform artifact stores in Phase 20.
