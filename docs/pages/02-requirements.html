02 Requirements

Shall / should / later. Prototype scope is explicit so implementation does not silently become a vehicle program.

IDs prefixed REQ-P are prototype. They are not OEM production requirements and are not ISO 26262 ASIL allocated.

5. Non-functional

  • Latency (target): CAN RX ISR to queue < 50 µs typical; gateway CAN→BLE not real-time hard.
  • Reliability: bus-off recovery policy; WDT reset with reason in NVS.
  • Safety: fault state machine; safe state = TX silent + outputs default. Not ASIL rated.
  • Security: prototype auth, session lock, rate limit. Not UNECE R155 certified.
  • Test: each module ships unit tests with Setup/Stimulus/Expect/Timeout/Pass-fail/Cleanup.

7. Out of scope for the prototype

  • CAN FD, LIN, FlexRay, Automotive Ethernet
  • Production HSM, secure boot fuse programming as a certified flow
  • OEM-secret CAN databases
  • Legal OBD tool certification, emissions, or workshop tool homologation
