2. Recommended first implementation slice (after approval)

  1. Agent 16 — HAL headers + ESP32-C3 + Virtual ECU stubs
  2. Agent 03 — framework + error codes + comments standard
  3. Agent 04 + 08 — logger, WDT, health, one demo task set
  4. Agent 05 — CAN driver/service with test hooks
  5. Agent 20 — review that slice only

3. What each agent must produce

  • Code with function banners and line comments on non-obvious lines
  • State machine tables where the module has modes
  • Tests with Setup / Stimulus / Expected / Timeout / Pass-fail / Cleanup
  • No product logic inside drivers

4. Review agent protocol

Agent 20 does not edit first. It files CRITICAL / HIGH / MEDIUM / LOW. Fixes are a second pass, module-local.
