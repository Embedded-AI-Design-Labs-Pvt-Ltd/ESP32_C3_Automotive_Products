7. IPC envelope

typedef struct {
  uint8_t  src;
  uint8_t  dst;
  uint16_t type;
  uint32_t ts_us;
  uint16_t len;
  uint8_t  payload[AE_IPC_MAX]; /* or pool pointer + flag */
} ae_msg_t;

ae_status_t ipc_send(QueueHandle_t q, const ae_msg_t *msg, uint32_t to);
ae_status_t ipc_recv(QueueHandle_t q, ae_msg_t *msg, uint32_t to);

FreeRTOS types appear only in middleware headers. Protocols take function pointers for send/recv so they stay portable.
