# platform/protocols

Automotive protocol engines. No BLE GATT parsing. No product UX.

- `can_service` — filter, timeout, missing/unexpected, stats, bus-off policy
- `isotp` — SF/FF/CF/FC, timeouts, segmentation
- `uds` — client and server, services 0x10/11/14/19/22/27/2E/31/3E
- `obd2` — Mode 01/03/04/09 over ISO-TP
- `xcp_lite` — conceptual CTO/DTO mapping only
