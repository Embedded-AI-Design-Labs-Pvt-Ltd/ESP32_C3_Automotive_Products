# ESP32-C3 drivers — not implemented

ESP-IDF implementations of HAL (TWAI, UART, GPIO, I2C, SPI, ADC, PWM, NVS, WDT, NimBLE) belong here. Application code must not include IDF headers.

Arduino HAL remains under `ports/arduino/` until IDF is the primary MCU path.
